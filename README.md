# Перегляд кошика інтернет-магазину

Невеликий клієнтський вебзастосунок для асинхронного завантаження кошика з [DummyJSON](https://dummyjson.com/). Проєкт демонструє роботу з HTTP-запитами, станами завантаження, таймаутами та повторними спробами.

## Можливості

- Завантаження кошика за його ID.
- Перегляд загальної вартості кошика та деталей кожного товару.
- Індикатор завантаження з номером поточної спроби.
- Автоматичний повтор запиту: до **2 спроб** із паузою **1 секунда**.
- Обробка помилок HTTP і таймаутів.
- Тестовий режим, у якому перша спроба завершується штучною помилкою.
- Сценарії для перевірки помилок HTTP 404, HTTP 503 і таймауту.

## Запуск

Залежності та збірка не потрібні. Потрібен браузер і доступ до інтернету, щоб звертатися до DummyJSON.

1. Відкрийте папку проєкту у редакторі коду.
2. Запустіть `index.html` через локальний вебсервер, наприклад розширенням **Live Server** у VS Code.
3. Або запустіть сервер Python із папки проєкту:

   ```bash
   py -m http.server 8000
   ```

   Потім відкрийте у браузері <http://localhost:8000>.

4. Введіть ID кошика та натисніть **«Завантажити кошик»**.

## Тестування сценаріїв

Виберіть сценарій у списку перед завантаженням:

| Сценарій | Результат |
| --- | --- |
| Звичайний запит | Завантажує кошик із затримкою 3 секунди; таймаут запиту — 5 секунд. |
| Помилка HTTP 404 | Сервер повертає помилку 404; застосунок повторює запит і показує повідомлення про помилку. |
| Помилка HTTP 503 | Сервер повертає помилку 503; застосунок повторює запит і показує повідомлення про помилку. |
| Таймаут | Запит переривається після 2 секунд, якщо сервер не відповів. |

Прапорець **«Тестовий режим»** штучно завершує першу спробу помилкою на клієнті. Це зручно, щоб побачити повідомлення про повторний запит; наступна спроба виконується згідно з вибраним сценарієм.

## Структура проєкту

```text
├── index.html   # Розмітка сторінки та елементи керування
├── script.js    # Запити до API, повторні спроби та відображення результату
├── style.css    # Стилі сторінки
├── error.png    # Ілюстрація для повідомлення про помилку
└── README.md    # Опис проєкту та інструкція із запуску
```
